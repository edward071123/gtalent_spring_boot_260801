# Spring Boot + MySQL + Flyway 筆記

## 前置作業

1. 建立 Java Spring Boot 專案。
2. 將專案加入 Git / GitHub 版本控制。
3. 確認本機 MySQL 已啟動。
4. 確認 `.env` 已建立，並填好正式與測試資料庫連線資訊。

## 環境設定

建立 `.env` 與 `.env.example`。

`.env` 放自己的本機設定，不要提交到 GitHub。

`.env.example` 放欄位範例，方便其他人知道需要哪些設定。


## Maven 依賴

在 `pom.xml` 加入資料庫相關依賴：

- Spring Data JPA
- MySQL Connector/J
- Spring Boot Flyway
- Flyway MySQL
